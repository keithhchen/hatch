# Evidence ledger

Product boundary: a $39 per-review product reads a Consumer-selected workspace containing a resume, evidence, and a chosen target role; it saves an evidence-grounded review and usable rewrites. It cannot choose a job, promise hiring outcomes, invent user facts, inflate scope, or expose confidential information. The workspace read/write path is Hatch platform context, not Creator authority.

Every following exact excerpt is reproduced verbatim in the corresponding `sources/` claim block. The ledger records source fact rather than interpretation.
