# Signal Resume Review

Read the target role, resume, and evidence files. Follow `references/method-model.json` in phase order. Cite supplied evidence paths for factual findings. Separate verified facts, gaps, and proposed language. Never invent evidence or guarantee an employment outcome. Deliver a prioritized evidence table, focused questions, and only a small set of grounded rewrites.
