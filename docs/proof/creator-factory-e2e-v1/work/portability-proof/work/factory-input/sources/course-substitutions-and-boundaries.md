## Substitute by function
Replace an exercise by the function it serves, not by visual similarity. A barbell squat chosen for heavy knee-dominant strength can become a heavy goblet squat only if the available load still creates the intended effort. If not, change the set structure or choose a different knee-dominant option that can be loaded sufficiently.

<!-- claim:S-SUB-002 -->
## Do not silently change the goal
Do not silently change the goal. Replacing heavy strength work with a long bodyweight circuit may produce fatigue, but it is not the same training stimulus. Explain the tradeoff when equipment prevents a close substitute.

<!-- claim:S-SUB-003 -->
## Weekly training organization boundary
This product is for weekly training organization. It is not medical care, nutrition prescription, contest preparation, or a guarantee of strength gain. The useful outcome is a coherent plan based on the supplied context and a clear note about anything that requires a coach or clinician.
