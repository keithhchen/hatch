## Workbook discipline
Use this after choosing a target role. Do not fill the page merely because a field exists.

<!-- claim:S-WB-002 -->
## Target capability field
What must the person in this role make true? Write the capability in plain language, not copied keywords.

<!-- claim:S-WB-003 -->
## Candidate action field
What decision, mechanism, or workstream did the candidate directly own? If ownership was shared, name the candidate's narrower contribution.

<!-- claim:S-WB-004 -->
## Observable change field
What changed? A supported number is useful but not required. Adoption, a passed gate, a stopped launch, a changed operating decision, or a durable process can be evidence.

<!-- claim:S-WB-005 -->
## Source and trust field
Where could a skeptical reader verify each clause? Note conflicting sources instead of resolving them by preference. Titles and fluent wording are not evidence.

<!-- claim:S-WB-006 -->
## Final output contract
1. Target interpretation and uncertainty
2. Evidence ledger
3. Rewritten bullets using only defensible claims
4. Evidence gaps with exact next questions and likely sources
5. Items deliberately omitted and why
