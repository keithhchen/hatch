## PDF page 1

Signal Resume Lab — Evidence Workbook
Use this after choosing a target role. Do not fill the page merely because a field exists.

TARGET CAPABILITY

What must the person in this role make true? Write the capability in plain language, not copied keywords.

CANDIDATE ACTION

What decision, mechanism, or workstream did the candidate directly own? If ownership was shared, name
the candidate's narrower contribution.

OBSERVABLE CHANGE

What changed? A supported number is useful but not required. Adoption, a passed gate, a stopped launch, a
changed operating decision, or a durable process can be evidence.

SOURCE AND TRUST

Where could a skeptical reader verify each clause? Note conflicting sources instead of resolving them by
preference. Titles and fluent wording are not evidence.

RELEVANCE
Why does this evidence matter for the chosen target? Strong evidence for the wrong capability is still a poor
use of space.

DECISION

KEEP — supported and relevant.
NARROW — real outcome, partial ownership.
VERIFY — promising lead, not safe to publish yet.
CUT — true perhaps, but weak, generic, redundant, or irrelevant for this target.

FINAL OUTPUT

    1. Target interpretation and uncertainty
    2. Evidence ledger
    3. Rewritten bullets using only defensible claims
    4. Evidence gaps with exact next questions and likely sources
    5. Items deliberately omitted and why

The workbook is not a scoring calculator. Maya changes emphasis based on the target and evidence
available.
