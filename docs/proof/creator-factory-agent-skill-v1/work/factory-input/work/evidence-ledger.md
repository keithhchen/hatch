# Evidence ledger

Product boundary established before distillation: a $39 per-review product for a selected workspace containing a resume, supporting evidence, and target role. It reads those materials, returns and saves a target interpretation, evidence-grounded revision plan and usable rewrites, plus evidence gaps. It does not choose jobs, promise hiring results, fabricate scope, or expose confidential facts.

Each excerpt below is copied verbatim into `sources/` after its claim marker. Source facts are distinct from the derived rules in `factory-plan.json`.
