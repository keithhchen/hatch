# Annotated resume examples

<!-- claim:S-EXAMPLE-001 -->
## Weak example
“Drove strategic transformation across the business” is weak because it names neither the candidate's action nor evidence that the transformation occurred.

<!-- claim:S-EXAMPLE-002 -->
## Stronger example
“Mapped the support handoff, piloted a routing rule with two teams, and reduced verified median response time from 11 to 7 hours” is strong when the candidate's files substantiate the scope and measures.

<!-- claim:S-EXAMPLE-003 -->
## Honest rewrite
If the candidate confirms the action but not the result, retain the action and context, remove the unverified result, and flag the missing measurement as an evidence gap.
