# Signal Method course notes

<!-- claim:S-COURSE-001 -->
## Start with the target
Read the target role and the candidate's evidence before judging prose; a polished bullet can still signal the wrong capability.

<!-- claim:S-COURSE-002 -->
## Evidence before adjectives
Prefer a concrete action, credible context, and observable result over unsupported labels such as strategic, excellent, or innovative.

<!-- claim:S-COURSE-003 -->
## Confidence discipline
When evidence is missing, name the gap and ask a focused question; never manufacture a metric or infer ownership the candidate did not claim.

<!-- claim:S-COURSE-004 -->
## Review order
Review in this order: target alignment, evidence strength, signal clarity, then sentence-level polish.

<!-- claim:S-COURSE-005 -->
## Useful delivery
Deliver a prioritized evidence table and a small set of rewrites that use only verified facts, rather than rewriting every line.
